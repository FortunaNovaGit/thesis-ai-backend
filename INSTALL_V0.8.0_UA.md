# Оновлення v0.8.0 — Render + WordPress

1. **Зроби backup** WordPress БД/файлів або принаймні експорт сторінок перед тестом, щоб можна було відкотити зміни.
2. **Backend**: розпакуй `wordpress-multiagent-mvp-v0.8.0-render.zip` у локальний Git repository, замінивши файли, Commit → Push → дочекайся Render redeploy. Ніколи не коміть `.env`/API keys. Не змінюй `BACKEND_TOKEN_SECRET`.
3. Переконайся, що `/health` повертає `"version": "0.8.0"` та `"architecture_version": "artifact_pipeline_v3_visual"`.
4. **Bridge**: WordPress → Plugins → Add New → Upload Plugin → `thesis-ai-bridge-v0.8.0.zip` → **Replace current with uploaded**. Не видаляй старі дані вручну.
5. У AI Website Builder перевір статус Bridge 0.8.0, натисни `Перевірити з'єднання`, далі `Прогнати preflight`.
6. Якщо потрібен approved plugin, Bridge перевірить, чи доступний метод filesystem `direct`. Якщо ні, інсталюй approved plugin вручну через WordPress, потім повтори preflight. **Не вводь FTP/SSH паролі в агентні промпти.**
7. Перший тест — 3 сторінки, тільки Draft. За відсутності підтверджених фотографій завантаж 1-3 реальні фото в Media Library, додай до них ALT з тематичними словами для підбору.
8. Оціни Elementor сторінки, CTA, menu, SEO та лог. **Публічна homepage не зміниться, доки ти вручну не опублікуєш і не затвердиш потрібні сторінки.**

## Обмеження

Ця збірка — інтеграційний кандидат, не підтверджений на реальному EasyWP. У v0.8.0 немає автоматичного створення WooCommerce продуктів; секція товарів може відображати наявний каталог, але не замінює його налаштування.
