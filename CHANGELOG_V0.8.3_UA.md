# v0.8.3 — Visual Storefront + Safe WooCommerce Shop

## Виправлено за скриншотами Fortuna Nova

1. **WooCommerce Shop collision:** `shop` більше не надходить до `elementor-ensure-draft-page` або `set-page-seo` як звичайна чернетка, якщо це e-commerce. `configure-woocommerce` відповідає за створення/використання офіційної сторінки Shop. Чужа опублікована сторінка не перезаписується.
2. **Planning text у Hero:** внутрішні `section.items` більше не відображаються праворуч у Hero; декоративна композиція використовується, якщо немає релевантних фотографій із Media Library.
3. **Контент:** розширено фільтр внутрішніх формулювань; додано обережні visitor-facing fallback тексти для шоколадних магазинів, без вигадування фактів.
4. **Design System:** брендово нейтральний шоколадний visual preset (какао/крем/латунь) лише для запитів із шоколадною тематикою. Інші бізнеси не отримують цей пресет.
5. **Elementor layouts:** повноширинні секції, виразніший Hero, абстрактна арт-композиція без підроблених фотографій, редакційні product cards, мобільна адаптація через scoped front CSS.
6. **Visual products:** home page e-commerce автоматично отримує product showcase, навіть коли Design Agent пропустив його.
7. **Демо-товари:** точні назви товарів із запиту створюються чернетками як раніше. Опціональні заготівки `Демо-товар 01...03` створюються тільки якщо користувач явно просить демонстраційні/шаблонні товари і не вказав конкретних назв. Жодних цін, залишків і неправдивих характеристик.
8. **Preview каталогу:** якщо WooCommerce Shop порожній, авторизований користувач із правом `edit_products` бачить редакційні картки існуючих AI-чернеток і посилання редагування. Публічні відвідувачі бачать стандартний порожній Shop; чернетки не стають товарами у продажу.
9. **QA:** для нативного Shop archive не застосовуються Elementor-specific перевірки кількості секцій та CTA. Наявність сторінки і WooCommerce-товарів перевіряється окремо.

## Що не входить до цього релізу

- Немає генерації фотореалістичних зображень чи AI-банерів, немає автоматичного завантаження стокових фотографій.
- Чернетки товарів не можна купити; ціни, зображення, склад, умови доставки й оплати потрібно заповнити/підтвердити.
- Немає підтвердженого Playwright visual QA проти реального EasyWP. Локальні тести перевіряють структуру/контракти, а не вигляд живого сайту.
- Існуючі неопубліковані AI-сторінки можуть оновлюватися, проте опубліковані чужі сторінки не перезаписуються.
