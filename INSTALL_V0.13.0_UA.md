# Thesis AI v0.13.0 — інструкція оновлення та тестування

## 0. Передумови
- Встановлено **backend/Bridge v0.12.0** (або 0.11.0).
- Резервна копія WordPress. Нічого не видаляти.

## 1. Backend
1. Розпакуй `thesis-ai-backend-v0.13.0.zip` поверх репозиторію, переглянь `git diff`, commit/push.
2. **Render → Environment** (щоб картинки справді генерувались):
   - `ENABLE_IMAGE_GENERATION=true`
   - `OPENAI_API_KEY` — вже є, **не змінюй**.
   - Необов'язково: `MAX_IMAGES_PER_BUILD` (за замовчуванням 10, максимум 12), `IMAGE_GENERATION_CONCURRENCY` (3).
3. Не змінюй `BACKEND_TOKEN_SECRET`, `DATABASE_URL`, `BACKEND_PAIRING_SECRET`.
4. `/health`: `version=0.13.0`, `image_generation_ready=true`, `features.auto_imagery=section_slots_v1`.

## 2. WordPress Bridge
1. Plugins → Add Plugin → Upload → `thesis-ai-bridge-v0.13.0.zip` → **Replace current with uploaded**. Без Delete.
2. Очисть кеш, перевір версію 0.13.0, Preflight.

> Оновлюй обидва. Bridge 0.12 з backend 0.13 генеруватиме лише 3 старі ролі.

## 3. Тест
1. У брифі «Режим зображень» має стояти «Автоматично…». Не обирай власних фото Hero.
2. Запусти build Fortuna Nova (3 сторінки). У журналі: «Генеруємо зображення…», потім «Медіафайл … додано» для кожної картинки.
3. Медіафайли: нові файли `thesis-ai-<job>-<slot>.webp` з підписом «Ілюстративне AI-зображення».
4. Preview кожної сторінки: Hero з картинкою; секції переваг/процесу — заголовок поруч з картинкою (сторони чергуються); товари — широка смуга; «маніфест»/CTA — картинка на фоні, текст читабельний; FAQ/контакти — картинка збоку. Команда й цифри — без картинок.
5. Elementor: кожну картинку можна замінити звичайним способом.
6. Негативний тест: вимкни `ENABLE_IMAGE_GENERATION` → build має завершитись **успішно** без картинок, у журналі — попередження.
7. Mobile ≈390 px: без горизонтального скролу.

## 4. Діагностика
- «Daily image generation quota reached» — денний ліміт; сайт збудується без картинок.
- Картинок менше, ніж секцій: ліміт 10 або провайдер відмовив у частині (видно в журналі).
- Стиль картинок різний: напиши — посилимо спільний арт-дирекшн у промпті.
