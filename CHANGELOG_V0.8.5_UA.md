# Thesis AI v0.8.5 — Editorial Quality Gate + Distinct Elementor Layouts

## Головна мета

Прибрати технічні інструкції, повторювані тексти та однотипні секції з клієнтських сторінок. Це **проміжне покращення** на основі v0.8.4; не гарантія професійного дизайну без фотографій та справжнього browser QA.

## Backend

- Додано `app/content_quality.py`: визначення внутрішніх планувальних фраз, повторів абзаців між секціями й сторінками, повторів item-карток, порожнього Hero та небезпечних CTA.
- Content gate працює **після Design Agent і до WordPress build plan**. Якщо помилки залишилися, нові WordPress-зміни не виконуються; користувач бачить тип помилки, наприклад `home:repeated_body`.
- Збережено 5 агентів і Pydantic-контракт, без додаткового LLM-виклику для editorial gate. Якщо вже витрачено токени на планування, перевірка не повертає витрачені кошти.
- `reconcile_experience` тепер прибирає повні повтори тексту, небезпечні CTA замінює внутрішнім fallback, відкидає editor-only items; дозволяє Design Agent додати до двох релевантних секцій, які раніше відкидалися.
- Зміцнено роль Design Agent: кожна сторінка має свою функцію й повідомлення; відвідувач не повинен читати команди для адміністратора.
- Доменні безпечні fallback-тексти для шоколадного магазину та стоматології більше не звертаються до власника зі словами на кшталт «заповніть у WordPress».
- У build artifact додано невеликий `content_quality` record із підсумком перевірки.

## Elementor / CSS

- Відокремлено стилі секцій services / benefits / trust / process через `tai-card-grid-*` та `tai-feature-card-*`; у process додано редаговану нумерацію кроків.
- CSS застосовується лише на AI-owned сторінках, із адаптацією 3→2→1 колонки.
- На видимій головній більше не показується редакторський текст «Чернетка товару — додайте фотографію…». Демо-товари лишаються чернетками WooCommerce.
- Збережено Elementor V3 native editable widgets; ні MCP, ні V4 Atomic API автоматично не активуються.

## Що ще НЕ реалізовано

- Справжня генерація/завантаження фотографій і рекламних банерів, дизайн із верифікованих шаблонів для різних індустрій.
- Playwright на живому EasyWP, screenshot QA, повна оцінка семантики тексту, виправлення з урахуванням реальних desktop/mobile скриншотів.
- Elementor V4 MCP Adapter. Для нього потрібна явна авторизація адміністратора й окреме permission/ability discovery.
